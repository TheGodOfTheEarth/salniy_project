## 📌 О проекте

**AutoService Management System** — это учебный проект, разработанный в рамках курсовой/дипломной работы в **Московском автомобильно-дорожном государственном техническом университете (МАДИ)**.

Система предназначена для автоматизации ключевых бизнес-процессов автосервиса: от онлайн-записи клиентов до формирования заказ-нарядов и управления складом запчастей.

<br />

## 👥 Роли и возможности

Платформа поддерживает три роли с разным уровнем доступа:

| Роль | Возможности |
|------|-------------|
| 👤 **Клиент** | Онлайн-запись, просмотр статуса ремонта и стоимости, управление своим «гаражом» (список авто), история ремонтов по VIN/госномеру |
| 🔧 **Мастер-приёмщик** | Поиск клиентов, создание карточек клиента и авто, формирование заказ-нарядов (работы + запчасти), управление складом, назначение механиков |
| 👑 **Администратор** | Управление ролями пользователей, корректировка записей клиентов, добавление/удаление ремонтных боксов, дашборд загрузки сервиса |

<br />

## 🛠️ Технологический стек

| Направление | Технологии |
|-------------|------------|
| **База данных** | PostgreSQL 16 |
| **Бэкенд** | C# / ASP.NET Core (.NET 10) |
| **ORM** | Entity Framework Core (Npgsql) |
| **Аутентификация** | JWT (JSON Web Tokens) |
| **Документация API** | OpenAPI 3.0 / Scalar UI |
| **Контейнеризация** | Docker / Docker Compose |
| **Контроль версий** | Git / GitHub |
